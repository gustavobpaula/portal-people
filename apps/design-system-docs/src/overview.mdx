# Design System — Portal Pessoas

Esta é uma aproximação visual local, não oficial e substituível para o case. A API pública é `@portal/design-tokens` e `@portal/design-system-web`; consumidores não importam arquivos internos.

## Tema e acessibilidade

O incremento entrega somente `light`. Novos temas devem mapear os mesmos tokens semânticos em `[data-theme]`, sem modificar os componentes. Todos os controles usam elementos HTML nativos, foco visível, alvos de ao menos 44 px e movimento reduzido quando solicitado pelo sistema.
